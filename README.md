
# Bird Gallery

A simple React application displaying a gallery of three birds.

## Features

- Bird data stored in a separate `data.js` file
- Passing data between components using props
- Rendering images using the `map()` method
- Practicing React state with `useState()`
- Responsive image gallery

## Technologies

- React
- JavaScript
- HTML5
- CSS3
- Vite

## Getting Started

1. Clone the repository:
   `git clone https://github.com/LeahLogic/bird-gallery.git`

2. Open the project folder:
   `cd bird-gallery`

3. Install dependencies:
   `npm install`

4. Start the development server:
   `npm run dev`

## Project Purpose

This project was created as part of a React course to practice passing data from a parent component to a child component using props.
